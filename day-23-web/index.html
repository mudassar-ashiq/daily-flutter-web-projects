    How it works

    Pick a task, start the timer, and work on that one thing until the time runs out. Then take the break — get up, stretch, drink some water. After four focus sessions the break is longer. The page keeps your tasks, lengths and today's session count in the browser, so closing the tab does not lose them.

    Press the space bar to start or pause the timer when you are not typing in a box.
