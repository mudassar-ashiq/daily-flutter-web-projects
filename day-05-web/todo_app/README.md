# Today — a simple to-do list

A small to-do list in plain HTML, CSS and JavaScript. You can add tasks,
tick them off, delete them, and filter between all, to-do and done.
Tasks are saved in the browser with localStorage, so they are still
there after you refresh or close the page.

## What I practised

- Building a list with JavaScript instead of writing the HTML by hand
- Saving and loading data with localStorage
- Filtering a list (all / to do / done) and keeping the count right
- A bit of form validation — empty tasks are not allowed

## How to run it

Open `index.html` in a browser. No build step and no server needed.

## Files

- `index.html` — the page content and the form
- `style.css` — all the styling, plain CSS
- `script.js` — adding, ticking off, deleting and filtering tasks
