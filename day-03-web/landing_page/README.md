# Fresh Oven Bakery — landing page

A landing page for a small bakery in Sahiwal. It has a hero section with
the day's prices, a menu, a bit about the bakery, opening hours and an
order form for pickup.

## What I practised

- Semantic HTML: header, nav, main, sections, footer, and a real form
- Responsive CSS with a mobile menu that opens and closes
- A little JavaScript: the mobile menu, a daily special based on the
  day of the week, and form validation with a confirmation message

## How to run it

Open `index.html` in a browser. No build step and no server needed.

## Files

- `index.html` — the page content
- `style.css` — all the styling, plain CSS
- `script.js` — menu toggle, daily special, order form checks

The order form does not send anything anywhere — there is no server
behind it. When the form is filled in correctly it shows a summary
the customer can mention at the counter.
