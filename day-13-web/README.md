# Day 13 — Restaurant Menu Page (Web)

A menu page for a small desi restaurant, Lazeez Restaurant in Sahiwal.
It lists 20 dishes across 8 categories, with prices in rupees.

## What I practised

- Building a responsive page with CSS grid that drops to one column on a phone
- Filtering a list with JavaScript (category buttons and a search box)
- Keeping an order in a Map and working out the running total
- Adding and removing items with quantity buttons
- Sticky filter bar and small screen layout

## How to run it

Open `index.html` in a browser. No build step and no server needed.

Try it out: pick a category like BBQ, search for "karahi", and add a few
dishes — the order box at the bottom keeps the total for you.

## Files

- `index.html` — header, filter bar, menu grid and order box
- `style.css` — all the styling, plain CSS
- `script.js` — the menu data, filtering, search and the order total
